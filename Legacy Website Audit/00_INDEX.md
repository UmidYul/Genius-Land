## Журнал прогресса
- Этап I (инвентаризация) — выполнен.
- Этап II (модули) — выполнен для всех модулей; пустые модули описаны по формам и конфигурации.
- Этап III–IV (правила, процессы) — выполнены частично: финансы, посещаемость, оценки, дисциплина проверены экспериментально; договоры, приём, HR — по конфигурации.
- Этап V (роли) — по серверной матрице; проверка входом под ролями не проводилась.
- Этапы VI–XI — выполнены.

Использовались только законно доступные источники: интерфейс под учётной записью владельца, ответы API в этой сессии, публично загружаемый фронтенд-бандл (только перечни маршрутов, эндпоинтов и тексты интерфейса; код не копировался). Секреты, токены и чужие учётные данные не извлекались и не сохранялись. Персональные данные учеников в документацию не включены.

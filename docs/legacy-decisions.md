# Решения по правилам из legacy

Каждое правило, взятое из `Legacy Website Audit/`, применяется только после подтверждения Umid (см. `CLAUDE.md`, правило 2).

Статусы: **❓ на подтверждении** · **✅ принято** · **✏️ принято с изменением** · **❌ отклонено**

# Этап 7 — Дашборды и отчёты

## Промт

Продолжаем платформу Genius Land. Прочитай `CLAUDE.md`, `PRODUCT.md`, `docs/v1/PLAN.md` (§4) и общие правила в `docs/v1/prompts/README.md` — следуй им.

Задача: главные страницы для каждой роли и базовые отчёты с выгрузкой в Excel. Все цифры считаются из исходных данных (журнал, леджер) — никаких отдельно хранимых итогов, которые могут разойтись.

Работай в ветке `feature/v1-07-dashboards-reports`.

Сделай:
1. **Основатель**: оба филиала рядом и по отдельности — ученики, посещаемость сегодня и за неделю, заполнение журнала, начислено / оплачено / долг за месяц, должники, очередь утверждений. Переключатель «все филиалы / филиал».
2. **Директор**: то же по своему филиалу + классы с низкой посещаемостью и успеваемостью, незаполненные уроки, итоговые оценки на утверждение.
3. **Администратор**: сегодняшнее расписание с изменениями, уроки без отметок, ученики без родителей или без привязанного бота, заполненность классов.
4. **Учитель**: мои уроки сегодня (переход в «Мой урок»), незаполненные уроки, мой класс (для классного руководителя).
5. **Бухгалтер**: поступления за сегодня и месяц по способам оплаты, должники, авансы, ближайшие сроки.
6. **Отчёты** (каждый — фильтры по филиалу, периоду, классу; экспорт Excel; печать):
   - посещаемость: по классу за период, по ученику, хронические пропуски (порог — настройка);
   - успеваемость: оценки класса по предмету, итоговые за четверть, средний балл по классам;
   - заполнение журнала по учителям;
   - финансы: начисления и оплаты за период, должники с возрастом долга, акт сверки по ученику, касса за день;
   - контингент: ученики по классам и группам, движение (прибыли/выбыли) за период.
7. **Сверка цифр**: тест, что сумма в отчёте должников равна сумме сальдо по леджеру, а посещаемость в отчёте равна отметкам в журнале.

Права: каждый видит отчёты только по своей области. Основатель — оба филиала, директор и администратор — свой, учитель — свои классы, бухгалтер — финансы назначенных филиалов.

Производительность: дашборд открывается быстрее 1 секунды на объёме 800 учеников за год данных (сгенерируй нагрузочные демо-данные в отдельном сиде).

Открой PR в `main`.

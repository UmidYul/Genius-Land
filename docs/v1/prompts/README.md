## Как использовать
1. Откройте новую сессию Claude Code в репозитории.
2. Скопируйте текст нужного промта целиком (всё ниже заголовка «Промт»).
3. После PR проверьте результат и только потом переходите к следующему.

## Общие правила (каждый промт на них ссылается)
- Перед работой прочитать `CLAUDE.md`, `PRODUCT.md`, `docs/v1/PLAN.md`, `docs/legacy-decisions.md`.
- Ничего не брать из `Legacy Website Audit/` без вопроса Umid (правило 2 в `CLAUDE.md`). Уже принятое — в `docs/legacy-decisions.md`.
- Если этап упирается в открытый вопрос из `docs/v1/PLAN.md` §6 — спросить. Если сказано «сделать настройкой» — сделать настройку со значением по умолчанию из плана и явно сообщить об этом в PR.
- Вся бизнес-логика — в `packages/core`, с unit-тестами. UI и бот только вызывают её.
- Каждая операция проверяет право и область видимости (филиал!). Для новых операций — тесты доступа.
- Все строки — через словари uz/ru. Все экраны работают на ширине 360 px.
- Аудит для денег, оценок, правок задним числом, статусов, прав, настроек.
- Никаких выдуманных «реальных» данных. Сиды — явно помеченные демо-данные.
- Перед PR: `lint`, `typecheck`, `test` зелёные; обновить `CLAUDE.md` (команды, архитектура) и, если что-то поменялось, `docs/v1/PLAN.md`.
- В описании PR: что сделано, какие значения по умолчанию выбраны, что осталось открытым.

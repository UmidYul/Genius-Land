# Этап 0 — Фундамент

## Промт

Ты работаешь над новой платформой Genius Land. Прочитай `CLAUDE.md`, `PRODUCT.md`, `docs/v1/PLAN.md` (§2 Архитектура) и общие правила в `docs/v1/prompts/README.md` — следуй им.

Задача этапа: подготовить фундамент проекта, на котором будут строиться все модули. Бизнес-функций в этом этапе нет.

Работай в ветке `feature/v1-00-foundation`.

Сделай:
1. **pnpm-монорепо** по структуре из PLAN §2.1: `apps/web`, `apps/worker`, `packages/db`, `packages/core`, `packages/i18n`, `packages/ui`. TypeScript strict везде, общие tsconfig, алиасы путей.
2. **apps/web** — Next.js (App Router) + Tailwind. Подключи next-intl с языками `uz` (по умолчанию, латиница) и `ru`, переключатель языка, словари из `packages/i18n`. Формат дат ДД.ММ.ГГГГ, валюта UZS, часовой пояс Asia/Tashkent — общие утилиты форматирования в `packages/core`.
3. **packages/db** — Prisma + PostgreSQL 16. Пока только служебные таблицы: `Setting` (ключ, значение JSON, филиал или глобально, кто и когда изменил) и `AuditLog` (актор, действие, сущность, id, было, стало, причина, время, IP). Миграции, клиент, скрипт сида.
4. **packages/core** — каркас доменного слоя: единый тип результата/ошибки с кодами ошибок (тексты — из i18n), утилиты денег (BigInt в сумах, форматирование), времени (границы дня/месяца по Ташкенту), функция записи аудита, чтение настроек с кешем на запрос.
5. **apps/worker** — пустой Node-процесс с подключённым pg-boss и одной демонстрационной задачей; graceful shutdown. Бот пока не подключать.
6. **packages/ui** — дизайн-система: токены цветов (светлая и тёмная темы), типографика, базовые компоненты (Button, Input, Select, Table, Card, Dialog, Toast, EmptyState, Skeleton). Цвета и шрифты бренда не заданы — выбери нейтральную спокойную палитру и вынеси её в токены, чтобы потом заменить на брендовую. Используй скилл `make-interfaces-feel-better`.
7. **Каркас кабинета сотрудника**: боковое меню (на телефоне — нижняя навигация или выезжающее меню), верхняя панель (переключатель языка, профиль), страница-заглушка «Главная». Меню пока статическое; в этапе 1 оно будет строиться из прав. Mobile-first: всё работает на 360 px.
8. **Docker Compose для разработки**: postgres (+ отдельная БД для тестов). `.env.example` со всеми переменными.
9. **Качество**: ESLint, Prettier, Vitest (unit + интеграционные тесты с тестовой БД), Playwright (один smoke-тест: главная открывается на uz и ru). Скрипты в корне: `dev`, `build`, `lint`, `typecheck`, `test`, `test:e2e`, `db:migrate`, `db:seed`.
10. **GitHub Actions**: на каждый PR — install, lint, typecheck, test (с postgres-сервисом), build.
11. **README.md**: что это за проект и как запустить локально. **CLAUDE.md**: заполни «Development Commands» и «High-Level Architecture».

Критерии готовности:
- `pnpm i && docker compose up -d && pnpm db:migrate && pnpm dev` поднимает кабинет на uz/ru.
- CI зелёный.
- Ни одной захардкоженной строки интерфейса.

Открой PR в `main` с описанием по общим правилам.

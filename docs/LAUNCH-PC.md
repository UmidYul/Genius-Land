# Запуск на ПК-сервере школы (временно, до покупки VPS)

Цель: утром за 30–40 минут поднять платформу на ПК школы и открыть её учителям по домену через Cloudflare Tunnel.
Потом тот же код и та же база переезжают на VPS — учителя ничего не замечают.

> Точные команды и имена скриптов уточняются в этапе L1 (`docs/v1/prompts/L1-launch-pc.md`). Порядок шагов ниже не меняется.

---

## A. Сделать заранее — сегодня вечером (≈ 40 минут, большую часть — ожидание)

Эти шаги нельзя оставлять на утро: смена DNS может занять до нескольких часов, а установка Docker на Windows требует перезагрузки.

### A1. Cloudflare и домен (из любого компьютера или телефона)
1. Зарегистрируйтесь на cloudflare.com (бесплатный план).
2. **Add a site** → введите ваш домен → план **Free**.
3. Cloudflare покажет **два nameserver**. Зайдите к регистратору домена и замените nameserver'ы на эти два. Обновление — от нескольких минут до нескольких часов, поэтому сегодня.
4. Дождитесь письма «Your site is active on Cloudflare» (или статуса Active в панели).
5. **Zero Trust** → **Networks** → **Tunnels** → **Create a tunnel** → тип **Cloudflared** → имя `genius-land`.
6. На шаге установки выберите **Docker** и **скопируйте токен** (длинная строка после `--token`). Сохраните его в надёжном месте — это пароль к туннелю.
7. **Public hostname**: поддомен, например `app` (или пусто для корня домена), домен — ваш; **Service**: `HTTP`, URL: `web:3000`. Сохраните.

### A2. ПК-сервер
1. Электропитание: **сон и гибернация — «Никогда»**, после пропадания питания — включаться автоматически (в BIOS: *Restore on AC power loss → Power On*), подключить к **ИБП**, интернет — **по кабелю**.
2. Установите **Git** и **Docker Desktop** (Windows: при установке включить WSL 2; потребуется перезагрузка). В настройках Docker Desktop включите «Start Docker Desktop when you sign in».
3. Если Windows: включите автоматический вход пользователя, чтобы Docker стартовал сам после перезагрузки.
4. Проверка: в PowerShell `docker run --rm hello-world` пишет «Hello from Docker!».

### A3. Данные
1. Положите **JSON со старыми логинами** на ПК в папку **вне репозитория** (например `C:\genius-import\users.legacy.json`). **Никогда не кладите его в git** и не пересылайте в мессенджерах.
2. Подготовьте Excel-файлы для импорта (шаблоны скачиваются в разделах платформы): классы и группы, ученики, родители, сотрудники и назначения учителей, расписание. Без классов, учеников и расписания учителям нечего отмечать.

---

## B. Утром — запуск (30–40 минут)

| # | Шаг | Время |
|---|---|---|
| 1 | Скачать проект: `git clone https://github.com/UmidYul/Genius-Land.git` и перейти в папку | 2 мин |
| 2 | Запустить `scripts\setup.ps1` (Windows) или `scripts/setup.sh` (Linux). Ввести домен и токен туннеля из A1.6. Скрипт сам создаст `.env.production`, пароли и секреты, соберёт и поднимет всё | 10–15 мин (первая сборка) |
| 3 | Создать первого суперадмина: команда из вывода скрипта (телефон и пароль вводятся в терминале) | 1 мин |
| 4 | Импорт учётных записей: сначала пробный прогон `--dry-run` с путём к JSON → проверить отчёт → настоящий импорт | 3–5 мин |
| 5 | Удалить JSON с диска | — |
| 6 | Открыть сайт **с телефона по мобильному интернету** (не по Wi-Fi школы) — проверить, что домен открывается и вход учителем работает | 2 мин |
| 7 | Импорт Excel: классы → сотрудники и назначения → ученики → родители → расписание | 10–15 мин |
| 8 | Ручной бэкап: команда `backup now` из раздела C | 1 мин |

Если что-то пошло не так на шаге 2: в выводе скрипта будет команда для просмотра логов. Повторный запуск `setup` безопасен.

---

## C. Каждый день

- **Бэкап** создаётся сам в 21:00 в папку `backups`, хранится 14 дней. Раз в день-два копируйте свежий файл **с ПК** на флешку или в облако — если ПК сломается, бэкап на нём не поможет.
- **Обновление** после новых изменений в GitHub: `scripts\update.ps1` (сам делает бэкап перед обновлением).
- **Восстановление** из бэкапа: `scripts\restore.ps1` и выбрать файл.
- Если сайт недоступен: проверьте, что ПК включён, есть интернет и Docker Desktop запущен.

---

## D. Переезд на VPS (когда купите)

1. На ПК: ручной бэкап.
2. Скопировать файл бэкапа на VPS.
3. На VPS: установить Docker, `git clone`, `scripts/setup.sh` (тот же токен туннеля или новый).
4. `scripts/restore.sh` с файлом бэкапа.
5. В Cloudflare — туннель теперь работает с VPS; ПК выключить.
6. При желании — перевести платформу на домен geniusland.uz (после отключения старого сайта).

Логины, пароли и все данные остаются прежними.
